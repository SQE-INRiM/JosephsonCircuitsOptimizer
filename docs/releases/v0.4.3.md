# JosephsonCircuitsOptimizer v0.4.3

**4 November 2026 — Stable GUI and Results release**

This update consolidates the improvements merged after v0.4.2 into a stable baseline before further work on nonlinear feedback. The JCO Julia numerical workflow and the portable `.jco` project schema are unchanged.

## Highlights

### Results and optimizer analysis
- A single **Run** selector above Linear / Optimization / Harmonic Balance keeps the chosen historical run when switching results views or refreshing, and aligns **Export CSV**, **Simulation info** and **Delete run**. **Manage runs** sits beside **Refresh results**.
- **Optimizer Landscape** shows the search locations and an optional chronological trajectory with direction arrows. The evaluation slider lets users inspect the search in order.
- **Projection** represents all evaluated configurations on chosen X/Y coordinates. **Slice · Linear** overlays the exact stored Linear heatmap with fixed values for other parameters; points from outside the slice remain recognizable as projections.
- Separate markers distinguish the best **sampled optimizer** configuration (orange ring) from the minimum **stored Linear cell in the displayed slice** (small labeled diamond). Neither is automatically a global optimum.
- The separate, compact **History** view places evaluated and best-so-far objective above a divider, followed by plots for all optimizer parameters.

### Setup, running and navigation
- Refine Setup's Circuit → Device parameters → Sources flow, project title and Back/Next controls. Avoid misleading Optimization controls for fixed-device studies.
- Keep **Run** and context-sensitive stage actions in one place, and improve safe reuse of saved stages, cancellation and completed/empty-run handling.
- Simplify the top application menu: project actions, examples, Julia settings, About JCO and appearance settings. About includes program version, project credit and citation.
- Remove repeated Results status messages, redundant explanatory labels and Windows development launcher warnings; improve default Dark/Light handling.
- Future Windows installer builds recreate legacy desktop shortcuts so the current JCO application icon is used.

## Compatibility and distribution

- **JCO (Julia)** and **JCO GUI (Electron)** versions: `0.4.3`.
- Existing `.jco` projects and persisted numerical results remain supported. No change to the JosephsonCircuits harmonic-balance solver, numerical cost semantics or project file schema is introduced by this release.
- Julia remains an **external prerequisite**, not bundled in the Windows/Linux packages. Windows packages remain unsigned.
- The tag-driven GitHub Actions workflow builds a **Windows installer**, **Windows portable executable** and **Linux x64 AppImage**, then publishes them to GitHub Releases.
- **Nonlinear-feedback GUI development is not included**; it remains separate for a subsequent feature release, tentatively v0.5.0.

## Verification and scope

- This release incorporates the reviewed and merged changes in PR [#34](https://github.com/SQE-INRiM/JosephsonCircuitsOptimizer/pull/34) (shared Results navigation) and [#35](https://github.com/SQE-INRiM/JosephsonCircuitsOptimizer/pull/35) (Optimizer Landscape and History), together with the Setup, Run and top-menu refinements already in `main`.
- GUI regression tests, TypeScript/renderer build, GitHub Governance, and Windows/Linux packaging checks are the required release gates. Those checks are not a new independent Julia/HB scientific reference validation, and the Linux desktop runtime remains less extensively validated than Windows.
- Detailed changes are in [CHANGELOG.md](../../CHANGELOG.md). Older v0.4.2 assets remain available and unchanged.
