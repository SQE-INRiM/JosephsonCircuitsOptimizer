# JosephsonCircuitsOptimizer v0.4.2

**30 October 2026 — GUI, Results and usability release**

This update collects the October improvements already integrated in the unified JCO repository, without changing the JosephsonCircuitsOptimizer numerical optimization model or the `.jco` project schema.

## Highlights

### Scientific workflow and Results
- Explore **Linear** and **Harmonic Balance** results with single-configuration inspection or **two-point A/B comparisons**. The A/B inspector displays changes in source/device parameters and metrics, and overlays matching retained arrays without silently interpolating their frequency samples.
- **Export plotted curves as CSV** in both Linear and HB, in single-point and A/B mode. A/B CSV files contain separate labeled columns for A and B, with the original frequency samples in Hz. Incompatible X grids cannot be exported as an overlay.
- CSV export also covers Linear 1D metric curves and HB *Amplitude response* plots. For HB source-amplitude sweeps, axis labels follow the units saved with the run.
- Display source-amplitude units (A or dBm) using each run's original settings; older runs without saved settings keep the previous dBm/50 Ω display convention.

### Setup and application usability
- Introduce the new JCO Josephson-junction visual identity, native app icons and an improved scientific-first README.
- Add **50–150% desktop zoom**, keyboard shortcuts, and Light/Dark/System themes.
- Improve Julia code editing with syntax highlighting, line numbers and four-space **Tab / Shift+Tab** indentation.
- Preserve editability and clear obsolete fields when switching Fixed, Range and List parameter modes. Improve AC/DC source selection and add guidance for Linear-stage harmonics and intermodulation settings.
- Open `.jco` projects by **drag and drop** from any screen, with unsaved-change and active-run protection.

### Run lifecycle and performance
- Remove automatically only run directories confirmed to contain no numerical or potentially useful output; keep partial or uncertain results intact.
- Keep **Run remaining**, **Run all**, per-stage execution and cancellation controls in the **Run** screen only. Remove cross-screen floating run buttons; use a temporary notification after completion, failure or cancellation.
- Improve startup/GUI responsiveness by deferring unused Julia plotting initialization, cleaning up unused Julia dependencies, and documenting Windows Smart App Control compatibility.

## Compatibility and distribution

- **Julia/JCO** and **Electron GUI** package versions: `0.4.2`.
- Existing `.jco` projects and saved numerical datasets remain supported. This release does **not** alter the harmonic-balance solver, scientific cost semantics or project input schema.
- Julia remains an **external runtime prerequisite**, not bundled with the desktop packages.
- The tag-driven GitHub Release builds a **Windows installer**, a **Windows portable executable**, and a **Linux AppImage**.
- **Nonlinear feedback GUI controls are not part of v0.4.2.** They remain in draft PR #24 for a future v0.4.3.
